Extrude

Overview

Extrude is like pulling clay out of your model - select a face and extrude it to pull it out and create new geometry. It's the most-used modeling tool!

Understanding Extrusion

If there's one modeling operation you absolutely must master, it's extrusion. This single tool is responsible for creating a vast majority of 3D geometry across all skill levels.

What extrusion does: It takes selected geometry (faces, edges, or vertices) and creates new connected geometry by "pulling" it outward. Think of it like working with clay - when you pull part of the clay outward, you're stretching and adding material while keeping it connected to the original form.

The process is beautifully simple:

1. Switch to editing the mesh's components (vertices, edges, faces)
2. Select a face, edge, or vertex
3. Run the Extrude tool
4. Drag to pull the new geometry outward (or type an exact distance)
5. Confirm

Axis-Constrained Extrusion: Just like with transformations, you can constrain an extrusion to a single axis. By default most tools extrude a face along its normal (straight out from the surface); constraining it to the vertical axis instead extrudes straight up, perfect for creating walls or vertical features.

What You're Seeing

The visualization shows a stepped pyramid structure created through multiple extrusions. Each layer was created by selecting the top face and extruding upward, then scaling it slightly smaller. This technique of "extrude and scale" is fundamental to organic modeling.

Notice how each level maintains connection to the level below it - this is the power of extrusion creating unified, seamless geometry.

Extrude Types: Faces, Edges, and Vertices

The visualization below demonstrates the three types of extrusion:

Left (orange) - Face Extrude: The top face of the cube is extruded upward, creating a protruding column. This is the most common type and creates new faces automatically.

Middle (green) - Edge Extrude: A single edge is selected and extruded, creating a new face between the original edge and the new edge. Perfect for creating fins, borders, or extending geometry along a direction.

Right (blue) - Vertex Extrude: Individual vertices are extruded, creating edges from the original vertices to the new ones. This gives you maximum control for creating branches or tentacle-like geometry.

Each type serves different modeling needs. Face extrusion builds volume, edge extrusion adds details, and vertex extrusion creates branching structures.

Common Use Cases

Building forms: Start with a simple cube, extrude one face to create a protrusion, and keep extruding to build complex shapes organically.

Adding appendages: Creating arms, legs, or branches? Select a face where you want it to start and extrude outward.

Creating architecture: Extruding walls upward, creating window frames, adding detail to structures.

What makes extrusion powerful is that the new geometry stays connected to your mesh. This means no gaps, no separate pieces to worry about - everything remains part of a unified whole.
