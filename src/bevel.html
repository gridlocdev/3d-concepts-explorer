Bevel

Bevel replaces a sharp edge with a narrow face, or a rounded strip of faces, so the edge catches light the way real objects do.

Real edges are never perfectly sharp; even a knife edge is slightly round up close. A perfectly sharp edge in 3D gets no highlight, which is a common reason a model looks computer-generated. A small bevel fixes it.

  1. Select edges (or vertices).
  2. Run Bevel (some tools call it Chamfer).
  3. Set the width, and raise the segment count for a rounder profile.

Width and segments

Width sets how much of the edge is rounded; segments set how smooth the curve is, at the cost of more geometry. New, manufactured objects have small bevels. Wood, plastic and worn objects have larger ones.
