Bevel

Bevel replaces a sharp edge with a narrow strip of faces. Real edges are never perfectly sharp, and a bevel lets an edge catch the light.

Drag a model to turn it.

In your tool

  1. Select edges (or vertices).
  2. Run Bevel (some tools call it Chamfer).
  3. Drag to set the width, and raise the segment count for a rounder edge.
