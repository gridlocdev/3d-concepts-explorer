Loop Cuts

A loop cut adds a ring of edges all the way around a mesh, so you get more detail in one band without touching the rest.

Drag a model to turn it.

In your tool

  1. Run the loop cut tool (also called Insert Edge Loop, Swift Loop or Connect).
  2. Hover an edge to preview the loop, and set how many to add.
  3. Click to place it, then slide it into position.
