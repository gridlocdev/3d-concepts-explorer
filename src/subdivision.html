Subdivision Surface

Subdivision surface splits every face into smaller ones and smooths the result, turning a simple, blocky mesh into a smooth one.

You edit the simple cage and the tool generates the smooth surface from it, usually as a non-destructive modifier using the Catmull-Clark algorithm. Moving one cage vertex reshapes a whole region of the smooth surface.

Most tools let you set one subdivision level for the viewport and a higher one for the final render.

Keeping edges sharp

Subdivision rounds an edge more when the edges around it are far apart. Add loops close to an edge (support loops) to keep it sharp, or mark it with an edge crease. This is how hard-surface models get smooth panels and crisp corners from one mesh.
