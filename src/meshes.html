Meshes

A mesh is a shape built from vertices (points), edges (lines between points) and faces (the surfaces edges enclose).

Almost every model starts as a mesh. Moving a vertex moves every edge and face attached to it, so editing a mesh comes down to selecting vertices, edges or faces and transforming them.

The mesh only defines shape. Color and surface detail come later, from materials and textures.

Polygon count

More faces make curves smoother but cost memory and render time, and make the mesh harder to edit. Spend detail where the viewer looks: a character's face needs it, the sole of their shoe doesn't. Games set a polygon budget per model for this reason.
