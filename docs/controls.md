# Controls

|                                | Mouse                           | Keyboard | Touch                     |
| ------------------------------ | ------------------------------- | -------- | ------------------------- |
| Turn a model                   | Drag it                         |          | Drag it                   |
| Open a model in expanded view  | Click **Expand** in its corner  |          | Tap **Expand**            |
| Previous or next model         | Click the previous or next button | `←` `→` | Tap the previous or next button |
| Close the expanded view        | Click **Close**                 | `Esc`    | Tap **Close**             |
| Go to another concept          | Click it in the sidebar, or the previous and next links at the bottom of a page | | Tap it |

Dragging up and down tips a model forward and back, up to a limit, and dragging sideways spins it all the way round. The arrow keys work while the expanded view is open.
