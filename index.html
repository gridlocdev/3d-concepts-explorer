About This Guide

This interactive guide is designed to help you understand the core concepts of 3D modeling, whichever tool you use. Whether you're completely new to 3D or switching tools, these foundational concepts will help you build a solid understanding of how 3D graphics work.

Each page includes a TL;DR summary, detailed explanation, and an interactive 3D visualization powered by Three.js. Click any concept below to begin learning.

Core Concepts

Meshes

The fundamental building blocks of 3D objects - vertices, edges, and faces that define shape and form.

Normals

Invisible directional vectors that determine which side of a surface is "outside" and how light interacts with it.

Transformations

The three essential operations - Move, Rotate, and Scale - that you'll use constantly to position and modify objects.

Extrude

The most-used modeling operation - pull geometry outward to create new connected forms organically.

Loop Cuts

Add edge loops to increase detail exactly where you need it, maintaining clean topology while building complexity.

Bevel

Round off sharp edges to create realistic lighting and make your models look less computer-generated.

Subdivision Surface

Automatically smooth and round your geometry - model with simple shapes, render with organic curves.

Materials

Define surface appearance - whether objects look like metal, plastic, glass, or any other substance.

UV Maps

Unfold 3D surfaces into 2D space so you can paint textures and apply images with precision.

Lighting

Set the mood and make your scene visible - different light types create dramatically different atmospheres.

Camera

Your viewpoint into the 3D world - frame your scene with the same principles photographers use.

Shaders

Programs that run on your GPU to create custom visual effects beyond what standard materials offer.

How to Use This Guide

1. Start with Meshes: If you're new to 3D, begin with the Meshes concept and work through them in order.

2. Use the sidebar: Navigate between concepts using the sidebar on the left, which is available on every page.

3. Interact with visualizations: The 3D examples on each page are live and interactive - watch them animate to understand the concept.

4. Read both sections: Start with the TL;DR for a quick overview, then dive into the detailed explanation for deeper understanding.
